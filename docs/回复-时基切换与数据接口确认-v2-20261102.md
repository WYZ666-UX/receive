## 3. 补充披露（v1 没写够的一条）

### 同一个"点"里，CH1 和 CH2 相差**半个点间隔**

**原因**：ADC3 每次触发**只转换 1 个通道**（这是本芯片 + 本配置的实测行为，
寄存器 `SQR1` 的 `L=1` 名义上是 2 通道，但 DMA 实测每次触发只搬 1 个字）。

| 通道 | 采样时刻 | 相对关系 |
|---|---|---|
| **CH2**（麦克风，协议 CH2）| 触发 `2k` | 基准 |
| **数字通道 D1/D2/D3** | 触发 `2k` | **与 CH2 完全同刻** |
| **CH1**（电位器，协议 CH1）| 触发 `2k+1` | 比 CH2 晚 **1 次触发 = 半个点间隔** |

**换算成屏幕格数**（以 1ms/格 为例，1 格 = 1 ms = 50 个点）：

```
半个点间隔 = 0.5 × 20 µs = 10 µs = 0.01 格
```

**各档对照：**

| 档位 | 半间隔 | 折算格数 |
|---|---|---|
| 10ms | 100 µs | 0.01 格 |
| 5ms | 50 µs | 0.01 格 |
| 1ms | 10 µs | 0.01 格 |
| 500µs | 5 µs | 0.01 格 |
| 100µs | 约 1.1 µs | 0.01 格 |

**恒为 0.01 格，远小于评分要求的 0.2 格**，可以忽略。

### 但对你们有两个实际影响

1. **做"同一信号接模拟+数字，测相位偏差"时**：
   - 接 **CH2 + 数字通道** → **完全同刻，偏差 0**
   - 接 **CH1 + 数字通道** → 会看到 **0.01 格**偏移

2. **如果想彻底避免**：验收时把信号接到 **A0（麦克风输入 / 协议 CH2）**，不要接 A1（电位器 / CH1）。

> 这是硬件限制，不是 bug，也无法通过软件消除（除非每次触发都转换两个通道，而那正是我们排查过但芯片没有做到的行为）。
